# Spillehallen

En samling af små browserspil af Mikkel Folmer Festersen.

Spil dem på https://folmerfestersen.github.io/spil/

Hvert spil ligger i sin egen mappe som én selvstændig `index.html`. Nyt spil: lav en mappe, læg spillets html i den som `index.html`, og tilføj et kort i forsidens `index.html`.
